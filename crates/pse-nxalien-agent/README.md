# pse-nxalien-agent

Context blocks and specialist activation for nxalien

`pse-nxalien-agent` is part of the [Kosmocrates](https://github.com/lashsesh/pse) workspace —
the post-symbolic multi-layer epistemic operating system. See the project
[`README.md`](../../README.md) and [`docs/OVERVIEW.md`](../../docs/OVERVIEW.md)
for the layered architecture this crate slots into.

## What it does

Context block generation and specialist activation for nxalien.

Produces the [NXALIEN-CONTEXT] injection block, AGENTS.md, CLAUDE.md,
and .rules from a compiled NxAlienManifest.

## Add to your project

```toml
[dependencies]
pse-nxalien-agent = "0.1.0"
```
