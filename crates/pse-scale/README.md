# pse-scale

Multi-scale observation, Kuramoto clustering, Fiedler bisection for PSE

`pse-scale` is part of the [Kosmocrates](https://github.com/lashsesh/pse) workspace —
the post-symbolic multi-layer epistemic operating system. See the project
[`README.md`](../../README.md) and [`docs/OVERVIEW.md`](../../docs/OVERVIEW.md)
for the layered architecture this crate slots into.

## What it does

Hierarchical multi-scale observation layer for PSE (C18).

Provides hypercube universes, dimensional bridges, and scale ladders for
micro/meso/macro observation and cross-scale coarsening.

## Add to your project

```toml
[dependencies]
pse-scale = "0.1.0"
```
