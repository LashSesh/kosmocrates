# pse-cli

PSE command line interface

A command-line tool that ships with the [Kosmocrates](https://github.com/lashsesh/pse)
workspace.

## What it does

PSE CLI — Command line interface for the Kosmocrates.

## Run

```bash
# From the workspace root:
cargo run --release -p pse-cli
# or, after `cargo install --path .`:
pse
```
