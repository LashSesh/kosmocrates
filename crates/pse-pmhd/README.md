# pse-pmhd

Adversarial drill engine, hypothesis testing, monolith generation for PSE

`pse-pmhd` is part of the [Kosmocrates](https://github.com/lashsesh/pse) workspace —
the post-symbolic multi-layer epistemic operating system. See the project
[`README.md`](../../README.md) and [`docs/OVERVIEW.md`](../../docs/OVERVIEW.md)
for the layered architecture this crate slots into.

## What it does

Polycentric multi-hypothesis drill for PSE (C21).

Generates, opposes, evaluates, and commits structured hypotheses through
adversarial drilling. Deterministic under a fixed `(DecisionSpec, seed)`.

## Add to your project

```toml
[dependencies]
pse-pmhd = "0.1.0"
```
