# pse-core

DomainAdapter trait and Engine orchestrator for PSE

`pse-core` is part of the [Kosmocrates](https://github.com/lashsesh/pse) workspace —
the post-symbolic multi-layer epistemic operating system. See the project
[`README.md`](../../README.md) and [`docs/OVERVIEW.md`](../../docs/OVERVIEW.md)
for the layered architecture this crate slots into.

## What it does

PSE analytical engine and orchestrator.

Coordinates the full pipeline from observation ingestion through consensus,
carrier geometry, morphogenic updates, and crystal archival.

## Add to your project

```toml
[dependencies]
pse-core = "0.1.0"
```
