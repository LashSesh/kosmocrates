# pse-navigator

TRITON golden-angle spiral, SimplexMesh, spectral-guided exploration for PSE

`pse-navigator` is part of the [Kosmocrates](https://github.com/lashsesh/pse) workspace —
the post-symbolic multi-layer epistemic operating system. See the project
[`README.md`](../../README.md) and [`docs/OVERVIEW.md`](../../docs/OVERVIEW.md)
for the layered architecture this crate slots into.

## What it does

Spectral-guided pattern space navigator for PSE (C29).

Explores the design space using golden-angle spirals and spectral signatures
(quality, stability, efficiency) to guide search toward high-resonance regions.
