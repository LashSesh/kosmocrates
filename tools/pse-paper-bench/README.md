# pse-paper-bench

Comprehensive benchmark suite for the Kosmocrates — produces a Zenodo-ready paper artifact

A command-line tool that ships with the [Kosmocrates](https://github.com/lashsesh/pse)
workspace.

## Run

```bash
# From the workspace root:
cargo run --release -p pse-paper-bench
# or, after `cargo install --path .`:
pse-paper-bench
```
